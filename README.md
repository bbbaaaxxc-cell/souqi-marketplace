# سوقي Marketplace

هذا المستودع يحتوي على نسخة MVP من منصة marketplace عربية صغيرة لعرض المنتجات، إدارة الطلبات، والتحويل البنكي.

## مقدمة

المشروع يركز على حماية النظام منذ البداية مع وضع مبدأ "تصميم آمن في كل طبقة". الهدف هو إنشاء منصة يمكن تطويرها لاحقًا إلى نظام كامل مع بائعين وطلبات واتصالات آمنة.

## التقنيات المستخدمة

- Next.js 14
- TypeScript
- Tailwind CSS
- Supabase-ready structure
- React client state for MVP

## التشغيل

```bash
npm install
npm run dev
```

ثم افتح المتصفح على:

```bash
http://localhost:3000
```

## ميزات النسخة الحالية

- عرض المنتجات في الصفحة الرئيسية
- تصفية المنتجات حسب الفئة
- بحث المنتجات عبر اسم المنتج أو البائع
- تفاصيل المنتج
- طلب شراء مع رقم إحالة تحويل بنكي
- لوحة إدارة الطلبات
- إدارة حالة الطلبات من قبل المشرف
- دعم كامل للغة العربية (RTL)

## الثغرات الأمنية التي تم أخذها في الاعتبار

- تنظيف النصوص قبل الحفظ: `sanitizeText`
- التحقق من رقم الإحالة البنكي: `validateTransferReference`
- عدم اعتماد أي نص حرفي غير مُفلتر
- فصل عرض البيانات عن منطق التطبيق
- خطة جاهزة للنشر مع Supabase Auth و RLS

## قائمة التحسينات المطلوبة في الإنتاج

1. إضافة قاعدة بيانات حقيقية عبر Supabase/Postgres
2. استخدام Auth حقيقي مع JWT أو Supabase Auth
3. التحقق من صلاحية كل طلب على الخادم
4. توفير نظام ملفات آمن للصور
5. حماية من CSRF و XSS في طبقة الخادم
6. إضافة نظام ملاحظات واستثناءات
7. استخدام Role-Based Access Control (RBAC)
8. ربط بوابة دفع حقيقية في المستقبل

## ملاحظة مهمة

هذا المشروع الحالي هو MVP تجريبي، وليس نظام دفع كامل جاهز للنشر مباشرة. لا تزال هناك حاجة إلى:

- إضافة Back-end حقيقي
- ربط قاعدة بيانات فعلية
- تخزين بيانات مدعومة
- حماية مستوى الخادم

## التوصية النهائية

لأن هذا المشروع موجه لمرحلة الاختبار والتجربة والتعلم، فهو مناسب جدًا للبدء. في الإنتاج الحقيقي، سنضيف:

- Supabase Auth
- Postgres tables
- Row Level Security
- Server Actions أو REST API
- نظام صور ومرفقات آمن
- تقارير وتحليلات الأمان
